Переписка

В Telegram отправляется сохранённый черновик Джарвиса, в Discord — текст из поля приложения. При просьбе только подготовить ответ отправки нет. По прямой команде отправить дополнительное подтверждение не требуется. Telegram читает последние 30 сообщений и ищет по истории без окна приложения.
Если элементы не распознаются
В Discord проверь настройки доступности. Если приложение не раскрывает чат или кнопку отправки, Джарвис остановится и покажет причину. Telegram использует API и не зависит от элементов окна.
Аккаунт Telegram и подключение
Telegram · фоновое подключение
Чаты и сообщения доступны по API, даже когда Telegram Desktop закрыт. Запросы идут с этого компьютера в Telegram.
Первое подключение
Получи API ID и API Hash в my.telegram.org/apps. Пароль аккаунта и коды входа сюда копировать не нужно. Нужные компоненты Джарвис подготовит автоматически при подключении.
На телефоне: Telegram → Настройки → Устройства → Подключить устройство. Отсканируй QR и подтверди вход, если Telegram попросит. Джарвис проверит подтверждение автоматически.
Сессия хранится зашифрованной средствами Windows. Во время входа передача экрана и управление приостанавливаются. Пароль двухэтапной защиты не сохраняется и не передаётся Gemini.
